To run the app:
- env/bin/python3 run.py

Or use the installed entry point:
- env/bin/macos-grok-overlay

First launch: macOS will prompt for Accessibility permission (required for the Option+Space global hotkey). Once granted, a menu bar icon appears and you can toggle the Grok window with Option+Space.

To install it to launch at login:
- env/bin/macos-grok-overlay --install-startup
